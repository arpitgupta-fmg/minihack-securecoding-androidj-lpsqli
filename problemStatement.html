Challenge Overview

Welcome to the Minihack - Android Security Coding Challenge! You are given a fully functional Android app called MomoFactory — a food delivery app for momos. However, the app contains critical security vulnerabilities that need to be identified and fixed.

Your Goal: Find and fix all security vulnerabilities in the MomoFactory app. Your fixes will be validated automatically when you run the tests.
About the App

MomoFactory is a simple food delivery app with the following features:

User Registration
Sign up with username, password, and address
User Login
Authenticate existing users
Dashboard
View profile and membership status (Regular / Pro)
Admin Panel
Hidden admin functionality
Note: The app is intentionally vulnerable. Your task is to find and fix the security issues.
What's Wrong?

The app appears to work correctly, but something isn't right. Explore the code and see if you can spot the issues.

🔍 Look Closely at the Manifest
The app asks for more than it needs. A food delivery app only requires internet access and location.
Think: Does a momo delivery app really need camera and contacts?
🚪 Who Can Access What?
Some screens in the app are meant to be private. But are they really?
Think: Should the admin panel be accessible from outside the app?
💉 Login Seems Too Easy
Try logging in with: ' OR '1'='1' -- as the username. What happens?
Think: How is the SQL query being built? Is it safe?
👑 Becoming a "Pro" User
Try signing up with a username that might break the SQL query. Can you become a Pro member without paying?
Think: What happens if the username contains SQL code?
What To Do After Fix?
  • Compile and build your project
  • Run the MomoFactory app in an emulator

How to Run Tests

After fixing the vulnerabilities, run the following command in the terminal:

$ run tests
